A Flutter project focused on building a social media-style application using API integration and the Provider package.

## **Long Exam 1**

This exam focuses on creating a Facebook-style Flutter application using the DummyJSON API. The app includes login and registration screens, a splash screen, a news feed, profiles, post details, comments, notifications, and light and dark themes. User, post, and comment data are organized into models and loaded through service classes.

## **Long Exam 1: Discussion**

This activity helped me understand how Flutter screens, models, services, and APIs work together. The models organize user, post, and comment data, while service classes handle requests to DummyJSON.

Building the feed, profile, and post detail screens showed how data can be passed between screens and displayed through reusable widgets. The comment and like interactions also helped me practice managing interface state, while Provider makes the theme available throughout the app.

Overall, the exam improved my understanding of API integration, Flutter navigation, state management, and organizing an application into separate files and responsibilities.
